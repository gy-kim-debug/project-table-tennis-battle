## 미완료 및 알려진 문제
Phase 1 프로젝트/씬/코드 구현 및 자동 테스트 완료. 사용자의 직접 10회 랠리 검수 미완료. 최종 아트 없음. iOS Export Template 미확인/기본 경로 없음. Linux 환경에서는 Xcode/실기기 검증 불가. 최초 Godot 버전 확인 시 Fontconfig 캐시 경고가 있었으나 작업용 XDG 캐시/설정 경로로 게임/검증을 경고 없이 실행했다. 가상 OpenGL에서는 V-Sync 변경 미지원 경고가 있으며 실기기 성능 근거로 사용하지 않는다. Phase 0 점검 당시 초기 Git 커밋이 없었으며 기존 work 브랜치를 유지했다. 이후 사용자 요청에 따라 Phase 0 문서와 Phase 1 프로토타입을 main의 최초 커밋 대상으로 정리했다. 원격/사용자 identity는 유지한다.

## 기술적 위험
- 입력 지연 및 낮은 FPS에서도 판정 일관성: 단조 시계, 경계 테스트, 실기기 보정 검수.
- 히트 스톱/백그라운드와 시간 불일치: 공과 판정의 동일 시간 기준, 중단/복귀 테스트.
- 360×640 가독성과 다른 iPhone 비율: 최종 해상도 검토, Safe Area 좌표 변환, Nearest 표시 검수.
- 중복 피해/종료 후 콜백: 이벤트/세션 식별자와 상태 제한.
- 압박 및 AI 공식 재미: 제안값을 확정으로 취급하지 않고 Phase 2~3 플레이 기반 조정.
- 에셋 생성 시 방향/프레임 정렬: ASSET_SPEC 기준 확인 후 통합.
