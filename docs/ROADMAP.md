## 미완료 및 알려진 문제
Phase 1~5 프로토타입 구현과 자동 검증 완료. 사용자의 직접 10회 랠리, 재미·구도·사운드·경기 길이 검수 미완료. 전용 PerfectSwing/Hit/Victory/Defeat 스프라이트와 최종 폰트/언어·화면 디자인은 후속 폴리시 대상이다. iOS Export Template 미확인/기본 경로 없음. Linux 환경에서는 Xcode/실기기 검증 불가. 가상 OpenGL의 V-Sync 변경 미지원 경고는 실기기 성능 근거로 사용하지 않는다.

## 기술적 위험
- 입력 지연 및 낮은 FPS에서도 판정 일관성: 단조 시계, 경계 테스트, 실기기 보정 검수.
- 히트 스톱/백그라운드와 시간 불일치: 프로토타입의 45ms 표시 고정은 판정 시계를 바꾸지 않는다. 실기기에서 시각·입력 체감 검수.
- 360×640 가독성과 다른 iPhone 비율: 최종 해상도 검토, Safe Area 좌표 변환, Nearest 표시 검수.
- 중복 피해/종료 후 콜백: 이벤트/세션 식별자와 상태 제한.
- 압박 및 AI 공식 재미: 제안값을 확정으로 취급하지 않고 Phase 2~3 플레이 기반 조정.
- 에셋 생성 시 방향/프레임 정렬: ASSET_SPEC 기준 확인 후 통합.

## iOS 테스트 계획
환경/계정/템플릿 확인 → macOS에서 Export 및 Xcode 빌드 → iPhone 설치 → 터치·30/60/120Hz 기기 특성·프레임·UI/노치·오디오·재시작·일시정지/백그라운드 복귀·메모리·판정 체감 검수. 기종/OS/Xcode/엔진 버전과 결과를 기록. 사용자가 가진 기기에서 먼저 확인하고 다른 비율도 검토.

## 2026-10-15 실행 기준 에셋화
- [표준 에셋 키트 v2](ASSET_TEMPLATE.md)에서 탁구대·네트·라켓 면·접촉/타격/피격/결과 이펙트·UI 장식과 글꼴을 실제 파일로 만들고 런타임에 연결했다. 위 v1의 설계 전용 상태는 이 작업으로 대체됐다. 캐릭터 몸과 라켓 면의 모든 프레임을 합성하면 기존 전신 원본과 픽셀 단위로 일치한다.
- 좌표는 `layout.json`에서, 에셋 경로는 시각/UI/음향 프로필과 캐릭터 manifest에서 선택한다. 투영 해시, 셀 크기, 프레임·알파, 라켓 접촉점, UI 파일을 자동 검사한다. 직접 플레이와 iPhone 실기기 감각은 아직 검수하지 않았다.
