# 캐릭터 기본 포즈 원본

사용자의 직접 에셋 제작 요청에 따라 승인된 focused-court-v3 시안에서 캐릭터 디자인을 제작했다. 아직 개별 디자인 검토 대기이며 실제 128×128 게임 프레임/애니메이션은 미완성이다.

| 플레이어: 후방 대각선, 청록 유니폼/붉은 라켓 | 상대: 정면 대각선, 붉은 유니폼/푸른 라켓 |
|---|---|
| ![플레이어 원본](player_reference.png) | ![상대 원본](enemy_reference.png) |

각 파일은 실제 **1254×1254 RGBA PNG**이며 투명 영역/캐릭터 불투명 영역이 확인되었다. 배경처럼 보이는 검은색은 뷰어의 투명 배경 표시일 수 있다. 캐릭터 주요 실루엣은 파일 안에 여백을 두고 들어간다. 플레이어 원본 테두리에 alpha=1 잔여 픽셀이 있어 최종 규격화 때 정리해야 한다.

이 파일은 캐릭터의 외형/색상/방향/라켓을 정하는 고해상도 기준 원본이다. 최종 128셀의 도트 그리드, 투명 경계, 피벗, 프레임 정렬을 검증하지 않았다. 실제 게임 씬에는 아직 연결하지 않았다. 다음은 이 디자인을 기준으로 규격화한 기본 포즈와 Idle/Swing/Miss 제작이다.
