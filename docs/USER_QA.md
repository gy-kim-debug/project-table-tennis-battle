# 사용자가 나중에 실행할 검수 목록

현재 사용자는 실행할 수 없어 직접 플레이를 개발 후로 미뤘다. 아래 체크박스는 자동 검증과 별개이며 아직 모두 미확인이다.

## 실행 준비
Godot 4.6.3 stable에서 project.godot를 Import → F5. 기본 보통 난이도, 128×128 캐릭터/근접 경기장/프로토타입 효과음·영문 UI가 표시된다. iPhone 실행은 이후 macOS/Xcode/Export Template/서명 준비가 필요하다.

## Phase 1 조작/가독성
- [ ] 터치/클릭/Space로 공이 라켓 옆 원에 도착할 때 받아칠 수 있다.
- [ ] Perfect/Good/Bad/Miss 피드백이 입력 타이밍과 자연스럽게 맞는다.
- [ ] 너무 일찍 누르면 다시 눌러도 같은 공을 받아치지 못한다. 연타로 우회되지 않는다.
- [ ] 미입력 또는 너무 늦은 입력은 Miss가 된다.
- [ ] 공/그림자/바운드/라켓의 가독성과 등 뒤의 약간 높은 근접 구도가 적절하다.
- [ ] 직접 10회 연속 랠리 검수: Phase 2 실제 AI는 실패할 수 있으므로 여러 랠리에서 시도. 자동 테스트의 fixture 12회는 이 항목의 대체가 아니다.

## Phase 2 HP 전투
- [ ] 처음 양측 HP 100, 상대가 선택한 패턴의 공을 보내며 시작한다.
- [ ] 공을 정상적으로 주고받는 동안 HP가 줄지 않는다.
- [ ] 일반 공 Miss는 12, 금색 강한 공 Miss는 18 감소한다.
- [ ] 상대가 Perfect 리턴을 놓치면 18, Good/Bad 리턴을 놓치면 12 감소한다.
- [ ] HP/피해 숫자가 겹치지 않고 충분히 읽힌다.
- [ ] Miss 후 약 0.8초 뒤 새 랠리가 시작한다.
- [ ] 상대 HP 0이면 승리, 내 HP 0이면 패배. 결과 이후 입력/대기로 HP나 상태가 바뀌지 않는다.
- [ ] PLAY AGAIN을 누르면 양측 HP 100으로 복원하며 입력이 중복되지 않는다.
- [ ] P/우측 II로 정지/재개, R/Restart 동작이 자연스럽다. 화면 이탈/복귀 시 무입력 피해가 발생하지 않는다.
- [ ] 기본 AI의 실패 빈도와 경기 길이가 적절하다. 목표 1~3분은 아직 체감 검증하지 않았다.

## 이후 iPhone 필수 항목
- [ ] 노치/Dynamic Island/다른 화면 비율의 필수 요소 및 Safe Area.
- [ ] 터치 지연/판정 보정, 프레임/발열/메모리, 백그라운드 복귀.
- [ ] 효과음/음소거 저장/최종 에셋도 별도 검수.

문제 기록은 기기/OS/엔진 버전, 입력 방식, 판정 오차 표시, 재현 순서와 함께 남긴다. 고정 시드 재현이 필요하면 resources/balance/battle.tres의 fixed_seed=true, seed_value를 기록한다. 검수 후 변경 값은 GAME_DESIGN/ROADMAP에 반영한다.


## Phase 3 패턴/난이도/압박
- [ ] Pause 메뉴에서 EASY/NORMAL/HARD 선택 시 HP/압박이 초기화되고 정지가 유지된다. Resume 후 선택한 난이도로 플레이한다.
- [ ] 기본/빠른 스매시/높은 로브/낮은 드라이브/템포 체인지가 서로 구별되며 모두 고정 라켓 위치에 도착한다.
- [ ] 높은 로브를 충분히 기다리고 템포 체인지에 성급히 스윙하지 않는 조작이 자연스럽다.
- [ ] 빠른 스매시(금색)는 첫 서브에서도 나올 수 있고, 놓치면 18 감소한다.
- [ ] 쉬움은 느린 공/기본·로브 비중이 높고, 어려움은 빠른 공/스매시·드라이브 비중과 AI 수비가 강하다.
- [ ] Pause의 압박 수치가 Perfect +35, Good +15, Bad −15, 플레이어 Miss 초기화에 맞게 변화한다. AI Perfect/Good 수비는 25/10 낮춘다.
- [ ] AI Miss 뒤 새 랠리에서는 압박이 유지되고, 새 경기/난이도 변경에서는 0이다.
- [ ] 각 난이도에서 판정 정확도/화면 가독성/경기 길이/실패 빈도가 적절하다.

현재 수동 검수 항목은 완료로 표시하지 않았다. 터치 PopupMenu와 기기 지연/화면은 실기기에서 별도 확인해야 한다.


## Phase 4 캐릭터 수동 검수 대기
- [ ] Idle 호흡/머리/체형 변화가 자연스럽고 프레임 사이 발이 흔들리지 않는지
- [ ] 플레이어의 낮은 백스윙·상승 타격·높은 팔로스루가 드라이브로 읽히는지, Miss와 구분되는지
- [ ] 투명 경계/셀 잘림/네트 레이어/HP 겹침이 없는지
- [ ] iPhone에서 실제 도트 밀도와 크기가 적절한지
- [ ] 나머지 환경 통합 후 승인된 v3 확대 구도와 집중도가 맞는지
자동 접촉/정지/재시작/규격 검사는 통과했으며 위 사람의 판단 항목은 아직 확인하지 않았다.


## 근접 경기장 수동 검수 대기
- [ ] 오른손잡이 플레이어 오른쪽 전경·오른손잡이 상대 왼쪽 원경의 등 뒤 시점과 시안의 집중 구도가 맞는지
- [ ] 360×640 및 실제 iPhone에서 탁구대·선수·공이 지나치게 크거나 작지 않은지
- [ ] 네트 앞뒤로 지나는 공과 접촉 링이 눈에 잘 띄는지
- [ ] 하단 HP/판정 문구가 전경 플레이어와 겹쳐도 읽히는지
- [ ] 5패턴과 3난이도에서 원근·공 속도의 체감이 자연스러운지
- [ ] 줄인 탁구대가 여전히 공·네트·타격 위치를 읽기 쉬운지, 상대 머리·상체·양팔·라켓 움직임이 충분히 보이는지
- [ ] 상대의 라켓 접촉이 높아진 공 시작점과 자연스럽게 맞는지

## Phase 5 프로토타입 연출 수동 검수 대기
- [ ] Perfect 접촉의 45ms 표시 정지·충격파·잔상이 조작 리듬을 방해하지 않는지
- [ ] 강한 공과 일반 공, Good과 Perfect, Miss와 피격이 한눈에 구별되는지
- [ ] 피격 숫자·승패 자세·결과 효과가 캐릭터/HP/메뉴를 가리지 않는지
- [ ] Pause의 SOUND OFF가 즉시 음소거되고 다음 실행에도 저장되는지; ON에서 9종 효과음의 크기와 겹침이 적절한지
- [ ] 각 난이도에서 실제 경기 길이가 목표 약 1~3분에 근접하는지; 짧다면 HP 피해/AI 능력을 재조정할 근거를 기록하기
