# 게임 화면 시안

사용자가 요청한 세밀한 도트 스타일의 첫 전체 화면 시안이다. v1은 초기 비교 시안이며 공식 제작 기준은 아래 v3이다. 게임 에셋 분리/실제 통합은 아직 진행하지 않았다.

![세밀한 도트 탁구 경기장 시안](detailed-pixel-court-v1.png)

청록색 플레이어/탁구대, 붉은 상대, 따뜻한 조명의 실내 경기장 구성을 검토한다. 이 PNG는 전체 분위기와 구도 검토용이며 실제 Godot 화면 캡처가 아니다. 현재 실행 게임에는 적용하지 않았다. 확정 후 픽셀 규격/라켓 접촉점/레이어/개별 스프라이트를 제작·검증한다.


## 128×128 캐릭터 방향의 두 번째 시안

![128 기준 도트 밀도 화면 시안](pixel-court-128-style-v2.png)

사용자 요청으로 기존 구도와 색감을 유지하면서 배경 소품/옷 디테일을 줄이고 도트 군집을 더 크게 정리했다. 전체 화면 시안이며 정확한 128×128 셀/스프라이트 시트는 아니다. 실제 에셋은 방향 승인 후 픽셀 그리드/셀 크기/투명 배경을 별도로 제작·검증한다. 게임 내부 해상도와 현재 실행 에셋은 변경하지 않았다.


## 경기 장면에 집중한 세 번째 시안

![배경 노출을 줄인 경기 화면](focused-court-v3.png)

사용자는 v2의 도트 스타일을 긍정적으로 평가하고 배경 노출을 줄여 플레이어/상대/탁구대/공에 집중하도록 요청했다. v3은 벽 장식/조명/벤치/식물을 제거하고 고정 구도를 가까이 재구성했다. 플레이어 하체 일부를 화면 밖으로 두고 탁구대/상대/공을 크게 표시한다. 검토용 전체 그림이며 실제 게임 카메라 이동이나 에셋 통합은 하지 않았다. 사용자가 v3의 구도·색감·도트 밀도를 공식 그래픽 제작 기준으로 승인했다. 128×128 실제 캐릭터 셀과 개별 게임 에셋은 별도 제작·검증한다.
